# Motto website (prototype)

One-page website prototype for Motto, an all-day breakfast café at 764 Queen St W, Toronto.

- `index.html` is the built page. It is fully self-contained (fonts, photos and icons are embedded), so it opens on its own in any browser.
- `src/src.html` is the source. Run `cd src && python3 build.py` to rebuild `index.html`.

Status: prototype, not live. The booking form does not send anything yet; it needs Motto's booking system. Customer and blogTO photos need permission before public use.
